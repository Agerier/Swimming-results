# Celiņš — современный интерфейс для live.swimrankings.net

Сайт берёт программу, стартовые листы и результаты соревнований со страниц
SPLASH Meet Manager (`https://live.swimrankings.net/<номер>/`) и показывает их
в удобном виде: программа дня, результаты по возрастным группам, фильтр по клубу,
поиск пловца, избранные пловцы, отсечки и составы эстафет, обновление каждые 30 секунд,
светлая и тёмная тема, три языка (RU / LV / EN).

## Как это работает

- `public/index.html` — весь интерфейс (один файл, без сборки).
- `api/*.js` и `server.js` — маленький сервер. Он нужен, потому что браузер не может
  сам читать чужой сайт. Сервер скачивает страницу соревнования и PDF, превращает их
  в JSON и держит в кэше 20 секунд, чтобы не нагружать источник.
- `lib/parse.js` — разбор страницы и PDF (без сети). `lib/pdf.js` — чтение текста из PDF.
- `lib/splash.js` — загрузка с источника: кэш, условные запросы (ETag / Last-Modified);
  если источник недоступен, отдаётся последнее сохранённое. `lib/handler.js` — общий обработчик.

Адреса экранов: `#m11609` — программа, `#m11609-e2` — дистанция, `#m11609-s` — пловцы.

Адреса API:

- `/api/meet?id=11609` — соревнование и программа
- `/api/results?id=11609&n=2` — результаты (`ResultList_2.pdf`)
- `/api/startlist?id=11609&n=4` — стартовый лист (`StartList_4.pdf`)

## Запуск на своём компьютере

Нужен Node.js 18 или новее.

```
npm install
npm start
```

Откройте http://localhost:3000 и введите номер соревнования, например `11609`.

## Публикация в интернете (бесплатно, Vercel)

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. На vercel.com нажмите Add New → Project и выберите репозиторий.
3. Ничего не меняйте в настройках, нажмите Deploy.

Через минуту сайт будет доступен по адресу вида `https://<имя>.vercel.app`.
На iPhone откройте его в Safari → «Поделиться» → «На экран Домой» — появится иконка,
как у приложения.

Любой другой хостинг с Node.js (Render, Railway, Fly.io, свой сервер) тоже подойдёт:
команда запуска — `npm start`, порт берётся из переменной `PORT`.

## Проверка

```
npm test
```

Тесты (`node --test`) разбирают сохранённые копии настоящих страниц и тексты настоящих PDF
из `test/fixtures/`:

- `meet_*.html` — страницы соревнований 11609, 11615, 11601;
- `*.tsv` — текст PDF в том виде, в каком его отдаёт `lib/pdf.js` (ячейки разделены табуляцией):
  результаты и стартовые листы 11609, дистанции 400 и 1500 м с отсечками, 200 м с отсечками
  в строке, эстафеты с составами, ничья, португальский протокол с лишними колонками;
- `*.txt` — те же списки простым текстом (как при копировании из PDF).

Отдельный тест собирает небольшой PDF и проверяет сборку строк по координатам.

## Как разбирается PDF

Meet Manager рисует каждую ячейку таблицы отдельным текстовым элементом. `lib/pdf.js`
собирает элементы в строки по координате Y, сортирует по X и соединяет ячейки табуляцией,
поэтому колонки не слипаются даже когда длинное название клуба наезжает на время.
Строка с отступом от левого поля получает табуляцию в начале — так заголовок возрастной
подгруппы (у поля) отличается от причины дисквалификации (с отступом).

Что умеет `lib/parse.js`:

- шапка страницы (название, город, строка события, дата, «Points: …», названия колонок)
  и нижняя строка «Splash Meet Manager, …» пропускаются на любом языке протокола;
- возрастные подгруппы, в том числе продолжающиеся на следующей странице;
- статусы DSQ, DNS, DNF, EXH, WDR и причина дисквалификации (`note`);
- ничья: строка без номера места получает место предыдущей строки;
- отсечки (`splits: [{ dist, time, lap }]`) — и отдельными строками «50m: …», и в строке результата;
- эстафеты: название команды, клуб, состав по этапам (`members` в результатах,
  `swimmers` в стартовом листе);
- лишние колонки (пол, номер лицензии, дополнительные очки).

Поля `splits`, `members`, `swimmers`, `relay` — дополнение к описанному API; у обычных
строк их нет.

Сервер запускался локально и ходил на live.swimrankings.net:

- **11609** (3. Olimpiskais gars VIII, Ogre): `/api/meet` — 25 строк программы (13 дистанций,
  12 награждений); `/api/results` для всех 13 опубликованных списков (257 строк) и
  `/api/startlist` для всех 13 (280 заявок). Число строк в каждом списке результатов и в шести
  стартовых листах сверено с независимым извлечением текста (`pdftotext`), отдельные записи
  (1-е место, DSQ с причиной, 19-е место с минутами, EXH) — с текстом PDF.
- **11615** (Koknese, мастерс): эстафета 10 × 25 м, 200 м с отсечками в строке, 400 м
  с отсечками отдельными строками — все 12 списков результатов и 3 стартовых листа.
- **11608** (Valmiera): все 13 списков результатов, три ничьи.
- **11601** (Tartu, плавание в ластах): эстафеты с составами, 400 м, ничьи, две возрастные
  категории в одном PDF.
- **11597** (Embourg, протоколы на французском): 1500 м, эстафета, слипшиеся колонки.
- **11580** (Mação, на португальском): лишние колонки, эстафеты, DSQ без времени.
- По одному списку из 11605, 11607, 11599.
- Интерфейс пройден в мобильном браузере (Chromium, 390 px): главная, программа, результаты,
  фильтры по подгруппе и клубу, стартовый лист, избранное, поиск пловца и клуба, светлая и
  тёмная тема, RU/LV/EN, эстафета, отсечки, сообщение для несуществующего номера.

Что не проверено:

- деплой на Vercel (функции в `api/` проверялись только через общий обработчик в `server.js`);
- соревнования с предварительными заплывами и финалами (Prelim / Final): страница такого
  соревнования (11593) разбирается, но опубликованных списков на момент проверки не было;
- отметка «сейчас» во время реально идущей сессии — проверена на подменённых данных
  (часть результатов скрыта), потому что к моменту проверки 11609 уже завершилось;
- установка на экран iPhone и работа в Safari.

## Что стоит знать

- Разбор PDF опирается на то, как Meet Manager оформляет списки. Если организаторы сильно
  меняют шаблон протокола, часть полей может не распознаться; под каждым списком есть ссылка
  на исходный PDF.
- В списках — имена детей. Перед публичным запуском стоит согласовать проект
  с Латвийской федерацией плавания. На странице соревнования бывает ссылка на файл
  результатов в формате LENEX (`results.lxf`) — с ним разбор PDF был бы не нужен.
- Избранные пловцы, язык и тема хранятся только в браузере пользователя.
- Vercel держит кэш функции в памяти отдельно для каждого экземпляра; общий кэш на 20 секунд
  даёт заголовок `Cache-Control: s-maxage=20, stale-while-revalidate=60`.
